# Wajdi Ben Ameur - Digital Identity Platform

Premium portfolio site for GitHub Pages.

## What this repo contains

- a modern one-page portfolio
- bilingual FR/EN content
- sections for business expertise, software engineering, AI and featured projects
- a project filter and a simple content model in JavaScript

## Local preview

Open `index.html` in a browser or serve the folder with a static server.

## GitHub Pages deployment

This repository is ready for GitHub Pages.

1. Push the `main` branch.
2. Enable GitHub Pages using the repository `Actions` or `Pages` settings.
3. The workflow at `.github/workflows/pages.yml` will deploy the site automatically.
